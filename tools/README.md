# tools — ベンチマーク・変換スクリプト

## Phase 0: ベンチマーク

M1 Max で 3DGS 学習の実測値を取る。**最初の意思決定ゲート。**

msplat の公表値（M4 Max, Mip-NeRF 360）と**同一シーンで**比較するため、`room` シーンを使う。

| | M4 Max 実測 | M1 Max 推定 | M1 Max 実測 |
|---|---|---|---|
| 7K iter (room) | 74 s | 2〜3 分 | **未計測** |
| 30K iter | ~700 s | 15〜20 分 | **未計測** |

推定は GPU コア数と帯域からの換算（32 vs 40 コア、400 vs 546 GB/s → 約 0.55〜0.6 倍）。

### 実測が推定から大きく外れた場合に見直すもの

- iteration 数の二段構成（7K / 30K）の妥当性
- ガウシアン数上限（現行案 150 万）
- 部屋分割の粒度（1 部屋 1 シーンか、フロア単位で統合するか）
